# Lily's Tacos — website

Single-page website for **Lily's Tacos (Restaurant & Patio)**, 29 Robinson St, Simcoe, ON.

- `index.html`: the whole site (HTML, CSS and JS in one file, no build step)
- `img/`: logo and hero dish image

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Before launch
- Confirm opening hours, menu prices and delivery partner with the restaurant.
- Replace the "Photo coming" cards and the patio placeholder with real photos.
